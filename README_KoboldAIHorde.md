# AI Horde Text Generation

- To generate text, use an app from the [list of integrations](https://aihorde.net/guis), such as
  [KoboldAI Lite](https://lite.koboldai.net) or [SillyTavern](https://sillytavern.app/).
- To use the Horde from software written for the OpenAI API, see
  [OpenAI-compatible chat completions](README.md#openai-compatible-chat-completions) in the main readme.
- To share your GPU, see [Contribute your GPU](README.md#contribute-your-gpu-become-a-worker) in the main readme.
